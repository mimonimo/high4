# HIGH1 POINT FLOW

> 하이원포인트 가맹점의 잔여한도와 사용현황을 결합해 폐광지역 상생 포인트의 소비 사각지대를 진단하는 대시보드
> 팀 **High4** · 공공데이터 활용 바이브코딩 경진대회

## 배포
- 배포 URL: https://mimonimo.github.io/high4/
- 저장소: https://github.com/mimonimo/high4

## 활용 데이터 (공공데이터포털, 제공기관: (주)강원랜드)
- **하이원포인트 사용현황** (파일데이터, 2021~2025년 5개년 · 총 2,376,780건, 주기성 과거 데이터 포함) — 수요
- **하이원포인트 가맹점 상세정보** (오픈API `getStoreInfo` · 1,548개소) — 공급
  → 캠프 중 1회 수집해 `data/merchants.json`으로 저장하는 정적 방식(API 실시간 호출 없음)

## 주요 기능
1. **가맹점 조회·소진 경보** — 상호·주소·업종·지역으로 검색, 포인트 잔여한도 표시, 소진 임박(잔액 10만원 미만) 경고 및 동일 지역·업종 대안 가맹점 추천
2. **사각지대 진단** — 지역(6)×업종(18) 108칸을 히트맵·산점도로 시각화, 공급공백/수요부진/과부하 자동 분류
3. **수요 리밸런싱 시뮬레이터** — 과부하 가맹점 수요를 유휴 가맹점(만액 242곳, 9.68억원)으로 이전 시 효과 시뮬레이션

## 핵심 발견
- 잔액 0원 가맹점 57곳 — 고객이 매장에서 결제 실패
- 사북읍: 가맹점당 593건(과부하), 53곳이 잔액 10만원 미만
- 태백시: 가맹점 562곳 중 127곳이 미사용(수요 부진)
- 영월군: 가맹점 70곳뿐이나 가맹점당 267건으로 태백 상회(공급 부재)

## 실행 방법
- 배포 URL 접속만으로 실행 (설치 불필요)
- 로컬: `git clone` 후 폴더에서 `python3 -m http.server 8000` → http://localhost:8000

## 데이터 처리
- 가맹점 API에 업종이 없어 상호명으로 업종 추정(키워드 규칙 + LLM), 이후 위치 기반 교차검증으로 보정
- **검증 ①** 무작위 150건 교차 검증(카카오 플레이스 등록업종 대조 88건 + 상호 기반 판정 62건) — 분류 정확도 **91.2%** (95% CI 85~95%)
- **검증 ②** 전수 위치 교차검증 — 1,548곳을 지오코딩 좌표 반경 150m의 카카오 플레이스 등록업종과 대조(857곳 매칭), 오분류 49건 수정·미분류 45곳 실측 업종으로 복구
- 업종 미분류 6.9%(107곳)는 진단 지표에서 제외
- `PNT_USABLE_AMT` = 잔여한도(최댓값 400만원 상한 확인)
- 개인정보(사업자번호·전화번호)는 배포 데이터에서 제거
- 가맹점 좌표는 카카오 로컬 API로 로컬에서 1회 지오코딩(1,548곳 중 1,546곳 확정, 2곳은 읍·시 중심 근사로 옅게 표시) — 배포물에는 좌표 숫자만 포함되며 API 호출·인증키 없음
